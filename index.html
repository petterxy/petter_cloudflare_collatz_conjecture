这个页面在做什么？

考拉兹猜想（1937）：任取正整数 n，偶数则 ÷2，奇数则 ×3+1，反复迭代。猜想断言：无论从哪里起飞，最终都会坠回 1。它看起来像小学数学，却难倒了整个数学界——Erdős 说："数学还没有准备好面对这样的问题。"（悬赏 500 美元）

本页把猜想变成一场无限延续的飞行表演：从 n=2 开始逐个起飞，实时画出每条冰雹轨迹（纵轴为对数高度），坠回 1 后立即测试下一个整数，永远继续。途中诞生的"最长飞行"与"最高峰值"纪录会被记入右侧榜单。全程使用 BigInt 精确整数运算，峰值再大也不会溢出。

诚实声明：计算机已验证所有 n ≤ 2⁶⁸ ≈ 2.95×10²⁰ 都回到 1，但猜想至今没有被证明——本页面是数值探索与可视化，不是证明。纯静态单文件，无任何外部依赖，可直接部署到 Cloudflare Pages / GitHub Pages。
